# Data attribution

`airports.csv` is a trimmed extract (IATA code, name, city, country,
latitude, longitude columns only; entries without an IATA code removed) of
the [OpenFlights](https://openflights.org) airport database
(`data/airports.dat` from https://github.com/jpatokal/openflights, retrieved
2026-09-28).

Per https://openflights.org/data.php, the OpenFlights airport, airline,
plane, and route databases are made available under the **Open Database
License (ODbL)**, with individual database contents under the **Database
Contents License (DbCL)**. Use requires acknowledging the source and
licensing derived works made available to the public under an equally free
license -- this file and its accompanying attribution notice serve that
requirement for this trimmed extract.
